·能干什么

⛽
记加油，不用自己算升数 填「单价 + 机显金额」，升数自动算准。有优惠（券、会员价）单独填，实付自动扣。
📊
算油耗，两种方法 加满法（加满到加满）和亮灯法（亮灯到亮灯），哪条数据够用哪条。算不出来就显示「—」，不编数字。
🔧
记保养、记费用 机油、刹车片、保险、停车费都能记，项目可以自己加。
🚗
多辆车分开算 油车、电车、混动都行，每辆车的账互不干扰。
📤
随时导出，不锁死你 Excel 报表给人看，JSON 备份用来换手机/重装后恢复。格式是纯文本，任何工具都能读。

·怎么装

  1. 点上面的「下载 Android 版」文件约 21 MB，存在手机的"下载"文件夹里
  2. 打开文件，系统会提示「禁止安装未知来源应用」点「设置」→ 允许这个来源 → 返回继续
  3. 安装完成，直接打开不需要注册、不需要联网，设好第一辆车就能开始记
升级前先备份。如果你已经在用旧版本，先去「设置 → 导出备份」存一份 JSON，再装新版本导入。 虽然覆盖安装不会丢数据，但万一出问题，有备份才有退路。

·常见问题

换手机 / 重装，数据怎么办
在旧手机「设置 → 导出备份」存一份 JSON 到文件管理器，传到新手机，在新手机上「设置 → 恢复数据」选它就行。

没有云端同步是故意的——有云就等于有服务器，有服务器就能被要求交数据。

恢复时会问你「覆盖式恢复」还是「追加导入」：换手机选覆盖，只想合并数据选追加。
为什么应用商店搜不到
没上架。上架要交年费、要过审核、要署真名，还可能被要求加广告和统计 SDK。

这个 App 的原则是「免费、数据在本地、不用登录」，上架和这三条冲突，所以只在 GitHub 和这里发布。
装的时候提示"文件损坏"或"解析包错误"
两种可能：
① 下载不完整——21 MB 的文件只下了一半。删掉重下，别用移动网络边下边断。
② 手机不是 64 位——2020 年前的老机型（尤其 32 位系统）装不了。

校验下载是否完整：文件大小应该是 21.4 MB。
